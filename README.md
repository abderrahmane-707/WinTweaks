# 🚀 WinTweaks

**WinTweaks** is a powerful Windows optimization and maintenance toolkit designed to improve performance, strengthen privacy, and enhance security through a centralized command-line interface.

---

## ✨ Features

* Activating Windows and Microsoft Office
* Disable Microsoft Defender
* Disable unnecessary background tasks
* Disable Windows telemetry
* Disable Windows Update
* Download Microsoft Office Suite
* Improve startup performance
* Install common software packages using Chocolatey (Package Manager)
* Remove temporary files
* Safely disable unnecessary Windows services
* Show Hardware Information
* View saved Wi-Fi passwords
* And more...

---

## 📥 Installation

Clone the repository:

```cmd
git clone https://github.com/abderrahmane-707/WinTweaks.git
```

---

## ▶️ Usage

1. Launch WinTweaks with administrator privileges.
2. Select a category from the main menu.

---

## ⚠️ Warning

WinTweaks modifies Windows services, registry settings, security policies, and system components.

Before applying major changes, it is strongly recommended to:

* Create a **System Restore Point**
* Back up important data
* Review each tweak before applying it

> Use this software at your own risk.
